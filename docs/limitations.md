
# TravelLens AI — Limitations and Future Work

## Implemented in the Current Prototype

- Responsive website layout.
- Searchable sample landmark records.
- Landmark detail display.
- Local image preview in the browser.
- Community story preview form.
- Basic form validation.
- Static JSON-based sample data.

## Not Yet Implemented

### AI Recognition
No trained CNN, TensorFlow Lite model, or OpenCV recognition pipeline is connected. Selecting an image only previews it.

### Historical Knowledge
The JSON file contains starter content. Sources must be checked and added before the records can be presented as fully verified.

### Community Contributions
The story form previews text in the browser. It does not save submissions to a database or send them to a moderator.

### Maps and Nearby Services
There is no live GPS, geofencing, route calculation, or connected nearby-attraction API.

### OCR and Currency
The prototype does not extract text from images or retrieve live exchange rates.

### Offline Support
There is no downloadable recognition model or offline landmark database package yet.

### Security
There is no backend authentication, user account system, or production access-control mechanism.

## Future Development Plan

1. Review and expand the landmark dataset.
2. Add reliable source references to each record.
3. Build a backend API and persistent database.
4. Train and evaluate a landmark-recognition model.
5. Integrate maps and nearby-service APIs.
6. Add moderated community contributions.
7. Evaluate multilingual and offline capabilities.
8. Test usability, accessibility, privacy, and security.

## Responsible Use

TravelLens AI is a student project prototype. It should not be relied upon as the sole source for emergency information, navigation, entry requirements, or travel safety decisions.
