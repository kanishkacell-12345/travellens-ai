# Development roadmap

## Phase 1 — Repository and backend
- Create GitHub repository
- Add README and `.gitignore`
- Start FastAPI and verify `/health`
- List and search sample landmark records
- Run tests

## Phase 2 — Mobile app
- Generate Flutter platform files
- Display landmark list from API
- Add loading, empty, and error states
- Add landmark detail screen

## Phase 3 — AI recognition
- Select a licensed image dataset
- Train and evaluate a baseline model
- Implement prediction endpoint
- Connect image capture and upload

## Phase 4 — Travel features
- Add sourced heritage content
- Add maps and nearby places
- Add OCR/currency/multilingual features incrementally
- Review privacy and security

## Phase 5 — Release
- Deploy API securely
- Configure production database and HTTPS
- Add screenshots and a verified demo
- Document limitations and test results
