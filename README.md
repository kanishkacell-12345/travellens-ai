## 📌 Project Overview
**TravelLens AI** is an AI-powered smart travel companion designed to solve key tourism challenges: scattered information, seasonal guide shortages, language barriers, and undocumented local folklore[span_2](start_span)[span_2](end_span)[span_3](start_span)[span_3](end_span).

- **Team:** She Coders[span_4](start_span)[span_4](end_span)
- **Track:** AI/ML + Open Innovation[span_5](start_span)[span_5](end_span)

---

## ✨ Key Features
- 📸 **AI Landmark Recognition:** Instant identification using live camera feed, OpenCV preprocessing, and CNN models[span_6](start_span)[span_6](end_span).
- 📜 **Verified Heritage & Stories:** Documented history and oral traditions from trusted sources[span_7](start_span)[span_7](end_span).
- 🗺️ **Smart Routes & Assistance:** Crowd-avoiding paths, nearby attractions locator, and 24/7 multilingual AI companion[span_8](start_span)[span_8](end_span).
- 💱 **Travel Tools:** Currency conversion with camera OCR and emergency service locator[span_9](start_span)[span_9](end_span).

| Layer | Technologies |
